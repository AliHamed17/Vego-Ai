# EXP-031 — BigUI formative usability

## Status

Proposal — not approved. No participant data is included in the repository.

## Design

After EXP-030 and interface stabilization, recruit 5–8 consented supervisors or
domain reviewers. Ask them to locate an experiment, explain its evidence class,
identify whether two runs are comparable, find the next gate, and state the
currently admissible claim.

Measure task completion, correctness, time, Single Ease Question scores, System
Usability Scale, navigation errors, and qualitative issues. Store raw records
locally using `BigUIStudyRecord-v1`; publish only validated aggregates.

## Claim boundary

Results are formative and descriptive. They do not support a population-level
usability or decision-quality claim.
