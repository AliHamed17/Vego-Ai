# EXP-034 — H-layer topology trade-off

## Purpose

Compare topology A (H1/H2/H3), topology B (Observer + Integrator), and topology
C (one modular agent with S1–S7) through the same canonical contract workload.

## Measures

Handoffs, duplicated context bytes, state ownership boundaries, failure
propagation breadth, recovery transitions, trace completeness, and canonical
output equivalence.

## Boundary

M-02 is deferred. The experiment reports a Pareto frontier and cannot select or
authorize a production topology.
