# EXP-032 — BigUI decision-support comparison

## Status

Blocked until EXP-031 is complete and the confirmatory interface and protocol
are frozen.

## Design

Use a counterbalanced within-participant comparison with at least 20 consented
participants. Compare the fragmented existing interfaces with the frozen
BigUI. The primary outcome is correct identification of evidence state and the
next action. Secondary outcomes are completion time, overclaim errors, and
confidence calibration.

## Claim boundary

A BigUI value claim is allowed only for the measured tasks and only when
correctness improves without increasing overclaim errors. Null and negative
results remain reportable.
