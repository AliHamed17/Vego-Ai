# EXP-026 — Human-Effort Study

Status: **Proposal — not approved.**

## Question

Does reusable memory reduce repeated review work or change escalation quality
under a controlled reviewer workflow?

## Design

- Obtain ethics/consent approval.
- Use timestamped before-memory and after-memory tasks.
- Control task order and carryover.
- Collect review time, repeated questions, confidence, and qualitative feedback.

## Metrics

- Per-item review time.
- Repeated-question rate.
- Review completion and abandonment.
- Escalation correctness.
- Reviewer confidence and workload response.

## Acceptance

- No queue-count proxy is reported as time saved.
- Missing timestamps are visible.
- Local pilot results are not extrapolated to scale.
- Reviewer privacy handling is documented.

## Boundaries

Human-effort reduction is unproven until this study is completed. The experiment
does not change runtime behavior.
