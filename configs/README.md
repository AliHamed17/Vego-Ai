# Configs

Central place for project-level configuration examples and reproducibility presets.

Existing runnable configuration currently lives inside:

- `VEGO-AI/framework/run_config.json`
- `VEGO-AI/eval/eval_config.json`
- `VEGO-AI/vego_visualizer_delivery/visualize_config.yaml`

Use this folder for shared presets, copies of publication configurations, and config manifests that point to exact experiment runs.
