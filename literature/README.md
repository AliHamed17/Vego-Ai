# Literature

Use this folder for reading workflow.

Suggested structure:

- `papers/`: PDFs or links, subject to copyright and sharing rules.
- `notes/`: reading notes based on `docs/templates/reading-note.md`.
- `bibliography.bib`: BibTeX entries.
- `hitl-resource-pack/`: curated Human-in-the-Loop / Human-AI collaboration resources for the VEGO-AI thesis.

Do not publish copyrighted PDFs unless you have rights to do so.
