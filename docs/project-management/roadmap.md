# Roadmap

## Milestones

| ID | Milestone | Status | Exit Criteria |
| --- | --- | --- | --- |
| M0 | Architecture baseline | In progress | Folder structure, Git hygiene, memory, and docs in place. |
| M1 | Data and artifact audit | Not started | Data sensitivity, provenance, and publishability recorded. |
| M2 | Reproducibility baseline | Not started | Framework/evaluator commands rerun or validated. |
| M3 | Experiment registry complete | Not started | Existing paper results mapped to experiment cards. |
| M4 | Test harness | Not started | Core evaluator/scoring/parsing tests added. |
| M5 | Paper evidence table | Not started | Claims linked to outputs and figures. |
| M6 | Thesis scaffold | Not started | Chapters, evidence map, and writing plan ready. |

## Weekly Review

At least once per week:

- update `experiments/registry.md`,
- update active issues,
- review risks,
- archive or label outputs,
- summarize progress in agent memory.
