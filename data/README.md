# Data

Data is split by lifecycle stage.

| Folder | Purpose |
| --- | --- |
| `raw/` | Original data exactly as received. |
| `external/` | Third-party or external reference material. |
| `interim/` | Temporary transformed data. |
| `processed/` | Cleaned or derived data ready for analysis. |

These zones are ignored by Git by default except for documentation placeholders. Store provenance and sharing rules before adding real data.
